## 测试目标
- 验证 `PT` 在不同 `QCFG granularity` 下的配置交互与数值行为。
- 重点覆盖：
  - `PER_TENSOR`
  - `X_WISE`
  - `Y_WISE`
  - `X_WISE_DIV2`
  - `Y_WISE_DIV2`

## 测试过程
1. 配置 A/B base 地址。
2. 使用 `identity` 作为 A。
3. 准备可区分的 B 输入模式。
4. 依次下发不同 granularity 的 `QCFG` header 与 payload。
5. 每次 `QCFG` 成功后发起 `MATMUL`。
6. 将导出矩阵与参考模型按当前 granularity 规则比对。

## 对应指标
- `QCFG` 模式覆盖数：
  - `4x4`：`5` 种模式
  - `8x8`：`5` 种模式
- `QCFG` 响应序列：
  - `0x00000101`
  - `0x00000102`
  - `0x00000103`
  - `0x00000104`
  - `0x00000105`
- 对应 `MATMUL` 响应序列：
  - `0x00000141`
  - `0x40000142`
  - `0x00000143`
  - `0x40000144`
  - `0x00000145`
- `scale index` 规则：
  - `PER_TENSOR`：所有元素使用 index `0`
  - `X_WISE`：使用 `row_idx`
  - `Y_WISE`：使用 `col_idx`
  - `X_WISE_DIV2`：使用 `row_idx >> 1`
  - `Y_WISE_DIV2`：使用 `col_idx >> 1`
- 导出数值指标：
  - `4x4` 每种模式导出 `16` 个元素
  - `8x8` 每种模式导出 `64` 个元素
  - 所有元素逐项与参考模型一致

## 测试成功判据
- `4x4` 和 `8x8` 两个结果文件都没有 `<failure>`。
- 每个尺寸实例都完成 `5` 个 `QCFG` 配置和 `5` 个导出事务。
- `QCFG` 响应必须完整出现 `0x101..0x105`。
- `MATMUL` 响应必须完整出现 `0x141/0x142/0x143/0x144/0x145`，其中缓冲区位轮转为 `0 -> 1 -> 0 -> 1 -> 0`。
- `4x4` 实例总导出元素数必须为 `5 × 16 = 80`。
- `8x8` 实例总导出元素数必须为 `5 × 64 = 320`。
- 导出元素全部与参考模型一致。

## 测试失败判据
- 任一模式缺少 `QCFG` 响应或 `MATMUL` 响应。
- 响应顺序不是 `0x101..0x105` 对应 `0x141..0x145`。
- 缓冲区轮转不满足 `0 -> 1 -> 0 -> 1 -> 0`。
- 任一模式的导出矩阵与参考模型不一致。
- 任一模式中 `scale index` 选择规则与当前设计语义不一致。

## 测试结论
- 本项测试结论为通过。
- 原因是 `4x4` 与 `8x8` 两个尺寸实例都完成了 `5` 种模式、`10` 次关键响应和对应全部导出元素校验，没有出现响应缺失、顺序错误、scale index 错配或 xUnit failure。
