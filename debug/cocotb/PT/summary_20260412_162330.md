## 5. 各测试简要结论
- `PT-BB-001`：`4x4` 与 `8x8` 两个实例都完成了 `2` 次 `dma_req`、`3` 次 `m_dma_req`、`3` 次 completion `irq`，关键响应序列固定为 `0x10 -> 0x11 -> 0x20 -> 0x00000001 -> 0x40000001 -> 0x00000003`。
- `PT-BB-002`：在 `2x2/4x4/8x8` 三个尺寸上共完成 `5` 组边界场景，累计校验 `420` 个导出元素，全部与参考模型一致。
- `PT-BB-003`：`4x4` 与 `8x8` 两个实例都完成 `5` 种 `QCFG` 模式；关键响应覆盖 `0x101..0x105` 和 `0x141..0x145`，共校验 `400` 个导出元素。
- `PT-BB-004`：`4x4` 实例中完整观测到 `0x80000200/201/202/203/206/207` 以及 `0x00000208 -> 0x80000208`，错误路径覆盖完整。
- `PT-BB-005`：`3x2` 实例中观测到唯一关键错误响应 `0x80000250`，且无任何 `dma_req` / `m_dma_req`。
- `PT-BB-006`：`4x4` 与 `8x8` 两个实例在固定回压模式下都完成 `2` 笔事务、`4` 次 `dma_req`、`2` 次 `m_dma_req`、`2` 次 `irq`。
- `PT-BB-007`：`4x4` 和 `8x8` 共 `20` 个随机结果文件全部通过，连同 `full_4x4_core(seed=10)` 内嵌随机实例，共覆盖 `288` 个随机 case。

## 6. 当前覆盖边界
### 已覆盖
- 黑盒端口级控制流
- A/B DMA 输入协议
- M export 输出协议
- 多尺寸数值正确性
- 量化模式与数值边界
- `miss/hit/M-window`
- backpressure 组合
- 多 seed 伪随机混合事务

### 未单列展开项
- A/B DMA `mid-stream error` 的独立 directed case
- `dma_done` / `m_dma_done` 成功路径下的长延迟 sweep
- 极端长 control queue 深压测
