## 指标映射
- legal / hit / M-window / QCFG / invalid / wrong_tuser / export_error 的随机混合
- `dma_req_ready` / `m_dma_req_ready` / `m_axis_tready` / `s_axis_valid` 的随机扰动
- profile 名与 seed 的可复现性

## 成功判据
- 20 个命名随机 profile 都必须被独立执行并写出各自结果文件。
- 每个 profile 必须完整执行 `PT_RANDOM_CASES=20` 个内部随机事务，并保持 profile 名与 seed 可复现。
- 随机事务必须覆盖 legal / hit / M-window / QCFG / invalid / wrong_tuser / export_error 的混合路径。
- 日志中不得出现 `m_axis_tdata mismatch`、`ctrl_resp mismatch`、`timeout` 或 AssertionError。

## 失败判据
- 缺少任一命名随机 profile 的结果文件或日志。
- 任一 profile 未执行完 20 个内部随机事务。
- 出现 `mismatch`、`timeout`、不可复现差异，或 profile 名与 seed 无法唯一定位问题。
